# Mysore Silk Guide (AAT-3 student project)
Static HTML/CSS site for a Google Search Console demo. Not affiliated with KSIC.
1. Push to GitHub, enable Pages (branch `main`, root).
2. Run `./set_base_url.sh https://<user>.github.io/mysore-silk-guide`, commit, push.
3. Add the Google HTML verification file (googleXXXX.html) to the repo root.
4. Submit `sitemap.xml` in Search Console.
Pages are generated from the content docx by `../_build/build_site.py` (no build step needed to host).
